# MyBLOOM modifications

This is a modified version of Bloom by Sehajveer Singh. The original project
and its attribution notices remain preserved in `LICENSE`.

Modifications by Deepak Pancholi:

- Removed the auto-updater and remote announcements.
- Removed IP-based geolocation and made weather opt-in with a manually chosen city.
- Removed remote Google Fonts and tightened the webview content security policy.
- Rebranded the display name and application identifier to MyBLOOM.
